Home / Architecture

System design

One research protocol. Pluggable execution.

ARGUMENTUM separates the research lifecycle and artifact contracts from the orchestration framework used to execute each stage. This keeps the process inspectable while allowing different workflow runtimes.

System layers

From researcher input to persistent artifacts.

A self-hosted service coordinates the work and stores the outputs in a researcher-controlled environment.

Researcher workspaceProjects, runs, workspace credentials, artifact retrieval and status.
FastAPI serviceAuthenticated API, tenant boundaries, request validation and orchestration entry points.
Research protocolQuestion framing, 13 ordered stages, role contracts and artifact schemas.
Workflow harnessNative, LangGraph, CrewAI Flow or Microsoft Agent Framework execution.
Research resourcesScholarly catalogues, optional document extraction and compatible model endpoints.
Persistence and queuePostgreSQL for records, Redis/RQ for queued work and persistent artifact storage.
Execution sequence

Specialists contribute to a shared evidence trail.

01

Frame and discover

The Research Director defines scope and search strategy. The Literature Scout gathers and screens metadata from configured catalogues.

02

Analyse and challenge

The Evidence Analyst maps claims to sources. Methodology and data roles challenge design, limitations and inference boundaries.

03

Synthesise and review

Synthesis and writing roles prepare a draft. An adversarial reviewer flags weaknesses before revision and integrity checks.
